# 手动测试

## 运行

- 调试：`F5` 打开扩展开发宿主窗口，改代码后在宿主窗口 `Cmd+R` 重载。
- 本机安装：`./scripts/reinstall.sh`，自动编译、打包、覆盖安装到 VS Code 和 Kiro，完成后手动重载窗口。
- 卸载：`code --uninstall-extension zhiyuan.vscode-devkit`（Kiro 用 `kiro`）

## 重载窗口

覆盖安装后，已打开的 VS Code 窗口仍运行旧版插件，必须重载窗口才会加载新版本。

`Cmd+Shift+P` 执行 `Developer: Reload Window`（中文界面为「开发人员: 重新加载窗口」）。多窗口时每个窗口分别重载。

`code` CLI 没有执行命令的参数（`--command` 不存在），无法由脚本触发重载。
