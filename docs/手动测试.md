# 手动测试

## 方式一：调试模式（开发中推荐）

1. 用 VS Code 打开本项目，按 `F5`（对应 `.vscode/launch.json` 的 Run Extension）。
2. 会自动启动 watch 编译，并打开一个新的「扩展开发宿主」窗口，插件只在该窗口中加载。
3. 在宿主窗口中打开一个 Git 仓库进行测试。
4. 改代码后，在宿主窗口执行 `Developer: Reload Window`（`Cmd+R`）即可加载新代码。

日志查看：宿主窗口中执行 `Developer: Toggle Developer Tools`，Console 中应能看到 `[vscode-devkit] 插件已激活`。

## 方式二：打包安装到本机 VS Code

验证真实安装效果（与其他插件共存、状态栏位置等）时使用。

```bash
./scripts/reinstall.sh
```

脚本会依次：编译 TypeScript、打包为 `vscode-devkit-<version>.vsix`、`--force` 覆盖安装。完成后在 VS Code 中执行 `Developer: Reload Window` 生效。

前置条件：`code` 命令可用，若不可用，在 VS Code 中执行 `Shell Command: Install 'code' command in PATH`。

卸载：

```bash
code --uninstall-extension zhiyuan.vscode-devkit
```

## 测试用例

建议准备一个临时仓库测试，避免误改真实项目分支：

```bash
mkdir -p /tmp/devkit-test && cd /tmp/devkit-test && git init && git commit --allow-empty -m init
```

### 状态栏显示

- [ ] Git 仓库中，状态栏左侧分支名右边出现复制图标和编辑图标，两者紧挨
- [ ] 悬停分别显示「点击复制当前分支名」「重命名当前分支」
- [ ] 打开非 Git 目录，两个图标隐藏
- [ ] `git checkout --detach` 进入游离 HEAD，两个图标隐藏
- [ ] 终端切换分支后 3 秒内状态恢复正常

### 复制分支名

- [ ] 点击复制图标，提示「已复制分支名: xxx」，粘贴内容正确

### 重命名分支（无远程上游）

- [ ] 点击编辑图标，输入框默认填充当前分支名
- [ ] 清空输入，提示「分支名不能为空」
- [ ] 输入与原名相同，提示「新分支名与当前分支名相同」
- [ ] 输入非法名称（如 `a..b`、`foo bar`），提示「分支名不合法」
- [ ] 按 `Esc` 取消，分支不变
- [ ] 输入合法新名称，提示「已将本地分支 ... 重命名为 ...（无远程上游）」，`git branch` 确认

### 重命名分支（有远程上游）

会推送新分支并删除远程旧分支，务必使用测试远程仓库。

- [ ] 对已 `push -u` 的分支重命名，弹出模态确认框
- [ ] 选择取消，提示远程分支未改动，`git branch -vv` 显示本地已改名
- [ ] 选择「同步远程」，远程出现新分支、旧分支被删除，`git branch -vv` 显示上游指向新分支
