# 手动测试

## 运行

- 调试：`F5` 打开扩展开发宿主窗口，改代码后在宿主窗口 `Cmd+R` 重载。
- 本机安装：`./scripts/reinstall.sh`，自动编译、打包、覆盖安装，完成后手动重载窗口。
- 卸载：`code --uninstall-extension zhiyuan.vscode-devkit`

## 重载窗口

覆盖安装后，已打开的 VS Code 窗口仍运行旧版插件，必须重载窗口才会加载新版本。

`Cmd+Shift+P` 执行 `Developer: Reload Window`（中文界面为「开发人员: 重新加载窗口」）。多窗口时每个窗口分别重载。

`code` CLI 没有执行命令的参数（`--command` 不存在），无法由脚本触发重载。

## 用例

测试仓库：

```bash
mkdir -p /tmp/devkit-test && cd /tmp/devkit-test && git init && git commit --allow-empty -m init
```

状态栏

- [ ] 分支名右侧出现复制、编辑两个图标，且紧挨
- [ ] 非 Git 目录、游离 HEAD 时隐藏
- [ ] 终端切换分支后 3 秒内刷新

复制

- [ ] 点击复制图标，剪贴板为当前分支名

重命名

- [ ] 空值、与原名相同、非法名（如 `a..b`）给出校验提示
- [ ] `Esc` 取消，分支不变
- [ ] 合法新名：无弹窗，状态栏更新
- [ ] 有上游的分支：改名后 `git branch -vv` 仍跟踪远程旧分支（如 `[origin/test-v1]`）
- [ ] 拉取/同步可合并远程旧分支的新提交，冲突在编辑器中解决后提交
- [ ] 推送到远程新分支：`git push -u origin <新名>`，之后 `git branch -vv` 上游变为新分支
- [ ] 远程旧分支保持不变，按需用 `Git: Delete Remote Branch...` 删除

改名保留上游后，直接 `git push` 会因 `push.default=simple` 要求同名而报错，需按上面显式指定新分支名推送。
